# Vela — Полное интерактивное финансовое приложение (React + TypeScript + PI Database)

Проект **Vela** («Your money, one step at a time») полностью реализован как интерактивный, персистентный фронтенд-прототип в стиле **Soft Glass** (с сохранением оригинальной палитры `#272e23`, `#74766d`, `#386641`, шрифта `Manrope` и 13 оригинальных иконок из Figma Make).

---

## 🚀 Как открыть и запустить

### Способ 1. Мгновенный запуск в браузере (без терминала)
Просто дважды кликните по файлу:
- [`index.html`](./index.html)

В этот файл уже собран актуальный билд React + TypeScript приложения со всеми стилями и логикой **PI Database (IndexedDB + localStorage fallback)**.

### Способ 2. Запуск режима разработки (Vite + React + TypeScript)
```bash
cd react-app
npm install
npm run dev
```
Для сборки продакшн-версии:
```bash
cd react-app
npm run build
```

## 🏗 Архитектура проекта (`react-app/src/`)

Вся бизнес-логика, финансовые расчёты, парсинг выписок и модели данных вынесены в чистые переиспользуемые TypeScript-модули, которые в будущем можно напрямую перенести в **React Native / Expo**:

1. **Типы и схема PI Database** — [`react-app/src/types/pi.ts`](./react-app/src/types/pi.ts)
   - Полные интерфейсы для `UserProfile`, `FinancialAccount`, `BalanceObservation`, `IncomeSource`, `ExpenseCommitment`, `FinancialObligation`, `DebtRecord`, `FinancialGoal`, `GoalAllocation`, `StatementImport`, `TransactionRecord`, `TransactionClassification`, `TransferMatch`, `UserConfirmation`, `RecommendationRecord`, `FinancialSnapshot`.
2. **Персистентное хранилище (IndexedDB)** — [`react-app/src/database/db.ts`](./react-app/src/database/db.ts) и [`react-app/src/database/seed.ts`](./react-app/src/database/seed.ts)
   - Автоматическое сохранение всех изменений в IndexedDB (`vela_pi_database_v1`) с резервным копированием в `localStorage`.
   - Поддержка двух режимов: **Demo Mode (Alex · 4 счёта в EUR/HUF/KGS)** и **Blank New User Mode (чистый профиль с 1-го шага онбординга)**.
   - Экспорт всей базы PI Database в `.json`.
3. **Реальный парсер банковских выписок (CSV)** — [`react-app/src/services/statementParser.ts`](./react-app/src/services/statementParser.ts)
   - Загрузка реальных локальных файлов через Browser File API (`<input type="file">`).
   - Валидация колонок, нормализация дат и сумм, дедупликация транзакций по хэшу, обнаружение пересекающихся периодов (`overlapWarning`), честный статус `unsupported_format` для PDF/XLSX без фабрикации фейковых транзакций.
4. **Сверка переводов между своими счетами и вопросы высокой важности** — [`react-app/src/services/reconciliationService.ts`](./react-app/src/services/reconciliationService.ts)
   - Автоматическое сопоставление внутренних переводов (`TransferMatch` между Revolut и Wise), исключающее двойной учёт расходов и доходов.
   - Генерация вопросов `UserConfirmation` только тогда, когда ответ меняет расчёт доступных денег или рекомендацию.
5. **Финансовый снэпшот и мультивалютный расчёт** — [`react-app/src/services/snapshotBuilder.ts`](./react-app/src/services/snapshotBuilder.ts)
   - Никогда не смешивает разные валюты (`EUR`, `HUF`, `KGS`) без конвертации.
   - Разделяет общие банковские остатки (`totalReportedBalance`), личные доступные средства (`personalAccessibleCash` с учётом `mixed` / `work_business` счетов), зарезервированные на цели средства (`allocatedToGoals`), предстоящие счета (`upcomingUnpaidObligations`) и свободный безопасный остаток (`uncommittedSafeToSpend`).
   - Определяет готовность данных: **State A** (`Action Ready`), **State B** (`Clarification Needed`), **State C** (`Limited Data`).
6. **Жизненный цикл рекомендации (One Next Step)** — [`react-app/src/services/recommendationService.ts`](./react-app/src/services/recommendationService.ts)
   - Поддержка статусов `proposed`, `adjusted`, `completed`, `declined`.
   - Внутреннее резервирование (`Reserve €40 now`) создаёт запись `GoalAllocation` из существующих средств (`Safety Cushion: €100 → €140`, `Safe-to-Spend: €100 → €60`), не создавая «воздушных» денег (`totalReportedBalance` остаётся `€1,000.00`).
7. **Детерминированный локальный ассистент** — [`react-app/src/services/assistantService.ts`](./react-app/src/services/assistantService.ts)
   - Отвечает на вопросы пользователя на основе живых данных `FinancialSnapshot`.

## 📱 Основные экраны и возможности

- **Onboarding (10 экранов)** — [`OnboardingFlow.tsx`](./react-app/src/components/onboarding/OnboardingFlow.tsx)
  - Экраны 1–10: Welcome → Create Account → Meet Vela → What Matters to You → Your Accounts (мульти-банк, мульти-валюта, назначение счёта, личные/рабочие средства) → Your Income → Your Commitments (базовые расходы, счета, долги с поддержкой неизвестного остатка) → Let Vela Connect the Dots (загрузка CSV) → Your Financial Picture (проверка находок) → Welcome to Today.
- **TODAY** — [`TodayView.tsx`](./react-app/src/components/dashboard/TodayView.tsx)
  - Главная карточка рекомендации (`Reserve €40 now`, `Adjust`, `Not now`), мультивалютный баланс, быстрые подтверждения, 4 рабочих быстрых действия (`Add income`, `Update balance`, `Upload Statement`, `Review`) и интерактивный список обязательств.
- **MY PLAN** — [`MyPlanView.tsx`](./react-app/src/components/dashboard/MyPlanView.tsx)
  - Карточка **Safety Cushion** с расчётом покрытия в днях и месяцах (`safetyCushionAllocated / essentialMonthly`), график **Cash Flow** с переключателем периодов, интерактивный **SVG Donut-график** категорий расходов (клик по категории открывает транзакции), **Savings Simulator** с ползунком ежемесячного взноса, управление целями и долгами.
- **ASSISTANT** — [`AssistantView.tsx`](./react-app/src/components/dashboard/AssistantView.tsx)
  - Живой чат с быстрыми чипами вопросов, историей сообщений и указанием источника данных из локальной базы.
- **Settings & PI Database** — [`SettingsModal.tsx`](./react-app/src/components/modals/SettingsModal.tsx)
  - Управление профилем, счетами, CSV-выписками, переключение между **Demo Mode** и **Blank New User Profile**, а также экспорт базы в `.json`.
