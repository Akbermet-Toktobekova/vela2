# user-inputs — сюда вы кладёте ВСЕ свои данные

Агенты берут данные **только отсюда** (и из ваших ответов в чате). Ничего не придумывают.
Формат — **любой** (PDF, DOCX, MD, TXT, CSV, JSON, XLSX, скриншоты). Агент сам переведёт в структурированный вид
и **покажет вам на подтверждение** перед использованием.

| Папка | Что положить | Кто использует |
|---|---|---|
| `secrets/.env` | API-ключи (Gemini, позже OpenAI). Просто впишите значения после `=` | Бэкенд (AI-клиент) |
| `action-catalog/` | Список действий, которые FinAgent разрешено предлагать: название, что делает, какие данные нужны, когда можно/нельзя, как считать эффект, на какие правила/источники опирается | Suggestion Generator, Checker, Impact Calculator |
| `as/sources/` | Сами источники (статьи, PDF, ссылки, исследования) | AS Database |
| `as/rules/` | Финансовые правила, пороги, формулы, утверждения (claims) со ссылкой на источник | AS Database, Checker, Priority Policy |
| `decision-policy/` | Weight profiles, правила выбора профиля, K_i (шкалы нормализации), λ_C, сценарии robustness, пороги. Можно пусто — заполним в интервью | Final Recommendation Engine |
| `synthetic/` | Синтетические данные для финального теста (CSV-выписки, JSON-профили, ожидаемые результаты) | E2E-тесты |
| `other/` | Всё остальное (заметки, требования, ключ Frankfurter, если понадобится) | Координатор |

## Правила
- Файл `secrets/.env` **никогда** не коммитится и не попадает в логи/промпты.
- Если что-то в ваших файлах неоднозначно — агент **спросит вас**, а не будет угадывать.
- Каждый принятый из ваших файлов факт записывается в `docs/coordination/DECISIONS.md` со ссылкой на файл.
