# Архив раннего прототипа

Эти материалы сохранены для восстановления истории и не используются текущими приложениями.

- `legacy-prototype/` — ранний автономный `index.html`, его Python-генераторы, `svgs.json`, старые копии иконок и прежняя инструкция. Относительная структура сохранена.
- `design-source/` — оригинальный файл Figma Make, дизайн-референс и миниатюра.

Рабочие исходники находятся в `react-app/`, `server/` и `shared/` в корне проекта. Актуальная инструкция запуска: [README.md](../README.md).

Список перенесённых файлов с исходными путями, размерами и SHA256: [manifest.json](../docs/coordination/evidence/cleanup/manifest.json).
