# Beta integration contract
Base /api/beta. Bearer opaque session token. JSON error {error:{code,message}}. Auth: POST /auth/register {name,email,password}, POST /auth/login {email,password} -> {token,user:{id,name,email},expiresAt}; POST /auth/logout; GET /auth/me; POST /auth/forgot-password {email}; POST /auth/reset-password {token,password}.
State: GET /state -> {version:number,state:PIDatabaseSeed,aiConsent:boolean}; PUT /state {expectedVersion,state,aiConsent} -> same. Auth user owns all entities, server validates and rebuilds snapshot. Unknown numbers stay null. No client financial totals accepted.
Imports: POST /imports {accountId,fileName,contentBase64} -> {id,status,statement,transactions,rejectedRows}; GET /imports/:id; POST /imports/:id/confirm {expectedVersion} -> state envelope. AI: POST /review -> {id,status,result}; GET /jobs/:id. Chat GET /chat -> {messages}; POST /chat {message,requestId} -> {messages,reply,status}. Privacy GET /export; DELETE /account.
Mobile client must implement configurable EXPO_PUBLIC_API_URL with base /api/beta; never use localhost as a phone default. Display missing address configuration clearly.
Auth module exported class BetaAuth taking constructor {database: DatabaseSync, sendResetEmail?: async(email,url)=>void, resetBaseUrl:string}. Methods register(name,email,password), login(email,password) -> session response; authenticate(token)->user; logout(token); forgotPassword(email); resetPassword(token,password). Methods may be async. It owns auth_* tables only. Uses Node scrypt and random hashed tokens. No dependency on store module.
Store exported class BetaStore constructor {filename?:string,key?:Buffer}. Public database:DatabaseSync; get(userId,key):unknown|null; put(userId,key,value):void; remove(userId,key):void; deleteUser(userId):void; close():void. All document payloads encrypted AES-GCM with user/key AAD, no default key for persistent storage. :memory: may generate ephemeral key. Backup method backup(destination):void. DPAPI key file resolved alongside database on Windows. Auth gets store.database.
Coordinator handles auth route integration and package dependencies. Mobile owns all App.tsx/src; no manifest edits. Storage owns store.ts only, auth owns auth.ts only. Handoffs record real commands/output. Agents never change canonical financial rules.
