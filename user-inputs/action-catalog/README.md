# Approved Action Catalog — ваши действия

Положите файл(ы) в любом формате. Для каждого действия желательно (если чего-то нет — агент спросит):

1. **ID / название** — например `EXTRA_DEBT_PAYMENT`
2. **Что пользователь делает** простыми словами
3. **Параметры** — сумма, валюта, цель/долг, дата; допустимые диапазоны
4. **Нужные данные (required inputs)** — какие поля PI обязательны
5. **Когда можно (eligibility)** и **когда нельзя (safety)**
6. **Критическое ли действие** (Priority Policy) и при каком условии
7. **Модель эффекта (impact model)** — как меняются R (резерв), F (сэкономленные затраты), G (прогресс цели)
8. **Трение (friction)** — время, число шагов, поддержка (для тай-брейка)
9. **Правила/источники**, на которые опирается (ID из `as/`)
