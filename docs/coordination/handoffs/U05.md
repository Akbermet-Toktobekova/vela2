The updated Android bundle returned HTTP 200 and contained the static names without the constructor call. Startup on the affected phone remains to be verified.

## Statement type detection

The Android picker derives the filename from the URI, which can have an opaque last segment. The upload now detects PDF by its header and uses the supplied MIME type for CSV and Excel when the filename lacks a supported extension. The attached file's header was recognized locally. Expo `npm run typecheck` passed and the updated Android bundle returned HTTP 200.
