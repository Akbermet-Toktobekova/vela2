# AS — Authoritative Sources

- `sources/` — сами источники (PDF, ссылки списком в .md, статьи).
- `rules/` — правила, пороги, формулы, утверждения (claims). Для каждого желательно указать источник.

Агент разложит это в таблицы `sources`, `claims`, `claim_source_mapping`, `financial_rules`, `financial_formulas`
и покажет вам на подтверждение. Ничего не добавляет от себя.
